# 04 Archive

O que saiu de cena: projetos concluídos ou abandonados, áreas que deixaram de existir, recursos que não interessam mais. Nada é apagado; é movido para cá com a estrutura preservada, para poder ser reencontrado. Um projeto arquivado ganha uma nota de fechamento de três linhas: o que foi entregue, o que ficou de fora, o que se aprendeu.
