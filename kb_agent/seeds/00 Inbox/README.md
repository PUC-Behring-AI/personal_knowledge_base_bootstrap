# 00 Inbox

Captura rápida. Tudo entra aqui primeiro, sem organizar: uma nota por ideia, link, trecho ou dúvida. Você cria as notas como preferir (Obsidian, celular, um arquivo `.md` solto); o assistente não captura por você. Ele só olha aqui no healthcheck e quando você pede para processar o inbox (`process-inbox`).
