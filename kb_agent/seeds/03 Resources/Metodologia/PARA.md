# PARA

Em uma frase: organize por **acionabilidade**, não por assunto. Quatro pastas, em ordem decrescente de urgência:

| Pasta | O que é | Teste |
|---|---|---|
| `01 Projects/` | Tem objetivo e fim | "Quando isso termina?" tem resposta |
| `02 Areas/` | Responsabilidade contínua, sem fim | Um padrão a manter, não um resultado a atingir |
| `03 Resources/` | Referência e interesse | Útil um dia, não acionável agora |
| `04 Archive/` | Inativo | Saiu de cena; nada é apagado |

## As notas circulam
Projeto concluído → arquivo. Recurso que virou insumo → linkado do projeto. Área que deixou de existir → arquivo. Item do arquivo que voltou a interessar → recurso ou projeto. A revisão semanal é quando isso acontece.

## O mesmo assunto em várias pastas
É esperado. "Estatística" pode ser um projeto (a disciplina deste semestre), uma área (a sua competência) e um recurso (papers guardados) ao mesmo tempo. O que decide a pasta é o que você vai *fazer* com a nota, não do que ela trata.
